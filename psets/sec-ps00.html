    Section Problem Set 0

    This assignment is designed to help you practice submitting your work on Gradescope and correctly matching each problem to the location of your solution in the PDF. By the end of this assignment, you should be comfortable with the submission process and confident that your work is properly organized for grading.
    🔗
    Solve each exercise below on its own page (or separate sheet if using paper), and clearly label each page with the problem number. Then scan or photograph your work—make sure each image is clear, in the correct orientation, and that the problem number is visible—and upload a single PDF to Gradescope.
    🔗
    Uploading is not the last step. Once your file is uploaded, Gradescope will prompt you to match each page to the corresponding problem number. This matching step is crucial: double-check your selections, since unmatched or mismatched pages may result in a penalty on future assignments. You can resubmit your work as many times as you like before the deadline, so use that to your advantage if you’re unsure.
    🔗
    This is a practice assignment. The problems themselves are intentionally easy—the point is to get comfortable with the Gradescope workflow before it matters for a graded problem set.
    🔗
